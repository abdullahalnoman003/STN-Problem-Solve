# Problem Solving Solutions

A curated set of 20 JavaScript problems to practice core algorithms and data structures.

## Overview

All solutions must be implemented in a single file: [`solution.js`](solution.js). Each problem has a predefined function name and signature  use them exactly as specified in [Questions.md](Questions.md).

## Getting Started

1. Read the problem statements in [Questions.md](Questions.md)
2. Implement your solutions in `solution.js`
3. Test with the given examples and your own test cases

## Guidelines

- Implement all 20 problems in **one single file** (`solution.js`)
- Use the exact function names and parameter structures provided
- Avoid hardcoded outputs  solutions must work for valid inputs
- Handle edge cases and consider time/space complexity
- For in-place problems (void return), modify the input directly
- Keep code clean and organized with clear comments per problem

## File Structure

```
├── Questions.md  # Detailed problem statements, signatures & examples
├── README.md      # Project overview
└── solution.js    # Your implementations go here
```
